# nxnative Easy 1.27

The Library is the home for device state. Its selected-game dossier explains
recorded signature expiry, differing prepared/observed game versions, relevant
source changes or missing history. Installed alone no longer implies Update.
Opening a game leads to **My game** and **Saves and backups**, with provenance,
per-device presence and account-free backup actions in context.

Build wrappers record the preparing Easy release/build/source and exact IPA path.
Validated install/renew receipts record signing release/build/time while renewal
retains preparation provenance. Legacy fields stay unknown; they are not guessed
from file timestamps. A newer launcher alone is not a required game rebuild.

Read-only iPhone export now performs a fresh scoped lookup for the selected game
before presenting a local backup destination. Committed Mac saves and checked
cloud revisions can also be copied into new local files. Existing backups,
working transactions and active saves are not overwritten. Cloud conflict choice
and active restoration remain in the game runtime; no direct iOS save writer or
new console access is introduced.

Validation: 128 fork tests passed (four environment skips), followed by 31 targeted
save/policy/client/localization/workflow tests and 13 provenance/documentation/
localization checks. Python lint has zero new findings. Native bilingual views
were rendered at 1160×800 and 1000×640. Screenshots use synthetic games and devices.
No real signing, installation, game compilation, device save export or cloud
propagation test was performed. See the [design record](../design/game-hub-2026-11.md),
[maintenance guide](../game-maintenance.md) and [save guide](../save-transfer.md).
