# nxnative Easy 1.26

## Player changes

- Open **Update or renew** for an existing game. Signature renewal reuses its
  recorded IPA; engine/game updates return to preparation. The existing helper
  retains account, team, device and app identity and performs the final checks.
- Open **Saves** to see received revisions in your chosen iCloud folder, inspect
  a complete revision, import a matching backup as a new branch, or prepare a new
  raw backup package. Existing versions and originals remain available.
- Switch exports are explicitly prepared backups, not console restores. A stock
  Switch 1 or 2 does not load arbitrary SD save folders. Console access requires
  a separately configured compatible method; Easy does not modify a console.
- Mario Kart World inspection links the reviewed upstream proposal separately
  from supported games. The supplied base v0 input differs from the draft's
  reported 1.8.0 Mac tests. No unmerged engine patches were imported.

## Local verification

The fork suite passed 125 tests with four environment skips. The targeted
interchange/updater run passed 36 tests, including native-engine synthetic
cross-device imports, exact-byte exports, conflict retention and missing-root
refusal. Documentation/localization passed 12 checks. Python lint introduced no
new findings; the supported catalog remains synchronized at 130 profiles.
The whole Swift target compiled. English/Spanish native synthetic captures and
minimum-window review states were inspected; primary actions remain visible.

The local WKWebView check verified changed SVG keyframe geometry, play/pause
acceptance, the reduced-motion frame and no network requests. Hidden-fixture
wall-clock playback was throttled, so it is not a visible-playback/FPS claim.

No real account login, signing, device installation, console operation, active
save restore or game compilation was performed. Physical iCloud delivery and
console/gameplay interoperability remain separate user tests. See
[save transfers](../save-transfer.md), [maintenance](../game-maintenance.md),
[visual provenance](../design/save-transfer-2026-11.md) and the
