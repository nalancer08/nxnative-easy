# nxnative Easy 1.31.5

- Buttons have consistent padded click areas, clearer supporting-action borders, larger icon targets and hover/pressed/disabled states. Native menus use the same visible button surfaces.
- Library and Compatibility no longer expose controls from the hidden preparation page. Returning to preparation keeps its form and current step.
- Installing or renewing from a game presents the installer from the visible workspace. An expired signature says **Renew signature** and opens renewal before proposing an optional iCloud upgrade.
- Disconnected phones explain that they must connect to back up a save. Search has a clear action and a readable no-results state.
- Supporting text, fields, step labels and metadata have stronger contrast. Library, Compatibility, search, Add game and Settings have consistent keyboard shortcuts.
- Manual update checks show their result on the screen where they were requested.

The [UI/UX audit](../ui-ux-audit-2026-11.md) and [design system](../design-system.md) record the findings, measured contrast and checks for future changes. Engine 1.0.1 is unchanged; this launcher update does not recompile games, change signing identities or replace progress.
