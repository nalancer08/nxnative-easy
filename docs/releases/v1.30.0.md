# nxnative Easy 1.30.0

The library now opens as a launcher: a searchable game list stays on the left,
with gameplay artwork, Play/Install, save revisions and device presence inside
the selected game. Compatibility and Settings have a working back route;
selection is remembered. Navigation controls accept the first click in an
inactive window and the hidden preparation screen is clipped to its content.

Easy manages `iCloud Drive/nxnative Easy/Saves` when the real system drive is
available. Existing custom folders and opting out are respected. Each rebuilt
iOS game still needs Apple's one-time folder permission; the signing account
is independent. Save conflict preservation, installation identity checks and
explicit signing/install consent stay in place.

Original orange 3D portal artwork replaces the handset/controller icon in the
Dock and app. A locally bundled Lottie scene accompanies the first-game welcome
and destination step; inactive/reduced-motion uses a resting pose. English and
Spanish READMEs contain current native screenshots with synthetic data.

Validation: 130 desktop tests passed (four environment-dependent skips), native
save/launcher tests and the unsigned iOS smoke build passed, the catalog and docs
checks passed, and Python lint added no findings. Native renders cover 760- and
1280-point widths in both languages. In a visible native animation fixture, the
Lottie frame advanced from 50.97 to 112.95 over two seconds; its reduced-motion
pose was frame 60. No real game was launched, signed, installed or restored by
these checks; cross-device iCloud delivery is not certified by a local fixture.
