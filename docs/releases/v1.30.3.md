# nxnative Easy 1.30.3

- Fixes iPhone/iPad preparation failing at the final app link because AVFAudio was missing. Completed shaders remain reusable; a failed build does not install anything on the device.
- Shows useful linker details and readable build stages instead of hiding the missing symbols behind a generic error.
- **Back up save** exports progress to a ZIP. **Copy game content** copies the large files needed to play and is separate from save backup or sync.
- Updating an existing game for iCloud now opens that game's update review. If a sync-capable IPA is already prepared, Easy offers installation without another compilation.
- Fixes backup/content-copy actions racing the native installer's startup, and clears an earlier operation's error when starting a new scoped game query.
- Offers a save backup in the existing-app installation review, before final installation consent. Signing-account login is not required for backup or content copy.

Keep the game saved and closed before exporting or updating. Existing app identity checks remain enforced; Easy never uninstalls the previous app automatically.
