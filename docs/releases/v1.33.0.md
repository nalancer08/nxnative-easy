# nxnative Easy 1.33.0

## More games, smaller shader build footprints

Easy 1.33.0 includes engine 1.0.4 and 44 new commits from the original project.

- Five new profiles: ŌKAMI HD, Sonic Superstars, Minecraft Dungeons II, The Legend of Zelda: Ocarina of Time (Switch 2) and Kirby Air Riders. The app, both README galleries and website now share 148 application profiles.
- More efficient shader builds: completed output goes into the compilation cache and a compact library image, reducing temporary file counts. Progress remains visible throughout preparation.
- Memory, video, texture lifetime, shader translation and iOS Metal fixes, plus validation of damaged compressed content before compilation.
- Preserves Easy’s library, installer identities, four touch profiles and conflict-safe save history.

Mario Kart World already has a working Mac build and first-lap test using a matching base-v0 dump. Full races, long sessions and iPhone/iPad remain unverified. Each game profile lists its own tested versions and devices.

Existing games receive engine changes when prepared again. Renewing a signature keeps the existing engine. This update does not uninstall games or delete saves, RomFS or original packages. Old-cache cleanup remains opt-in.
