# nxnative Easy 1.34.0

## Engine updates across graphics, preparation and controllers

Easy 1.34.0 includes engine 1.0.6 and 47 commits from original main through d777f0a3.

- Mario Kart World: corrects a shader-table entry that could stop preparation.
- Ocarina of Time and other Switch 2 profiles: Ampere/mesh shader, texture lifetime, memory and synchronization fixes.
- Compute pipelines can be prepared offline and retained in device archives.
- Rewriter fixes for jump tables and exclusive branches; intact NUP images are reused; extracted games recover their registered display version; multi-program games keep separate work folders.
- Controller identity/HID fallback improvements, optional press-a-button player joining, and screen-matched iOS picture shape.
- The synchronized app/README/website catalog remains at 148 application profiles.

Easy’s library, four touch profiles, signing identities and conflict-safe save history remain. Existing game apps receive the new engine when prepared again; renewing a signature keeps their current engine. Original files, RomFS, installed games and progress are preserved.

Mac bring-up evidence for Switch 2 does not certify iPhone/iPad. [Integration review and validation](https://github.com/nalancer08/nxnative-easy/blob/main/docs/upstream-reviews/2026-11-07.md).
