# nxnative Easy 1.31.1

- A compact launcher header with an original cartridge icon, animated brand response, and Back only when there is a previous page.
- Buttons respond across their visible surfaces, including the native destination selector and its popover actions. Device destinations are grouped into compact cards, and a duplicate one-image gallery is omitted.
- Each prepared platform shows its preparation date and code revision. The header opens an offline engine history with integrated commits, upstream base and update status.
- First launch offers iCloud using the macOS account, with an explicit local-only warning when skipped. The signing account remains independent; Settings can reopen iCloud setup.
- An original local Lottie follows a cartridge across Mac, iPad and iPhone. Selection transitions and button feedback respect the native flow.
- Updates are checked from the visible workspace and on foreground, with throttling and manual status. Discovery follows the latest published release, so an unreleased main commit cannot mask the last available update.
- Storage can reclaim checked Xcode intermediates as well as build caches. Original games, keys, prepared products, romfs and saves remain protected.

Existing iPhone/iPad games need the save-continuity runtime and their one-time folder permission to sync. This launcher update does not install, rebuild or change your games automatically.
