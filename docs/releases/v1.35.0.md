# Easy 1.35.0

Engine 1.0.10 integrates 89 original-main commits through cfbdd93ca5ca, preserving Easy's library, installation identities, four touch profiles and immutable save recovery.

- Adds DRAGON BALL: Sparking! ZERO, The Rogue Prince of Persia and ROMANCE OF THE THREE KINGDOMS XIV, with imported artwork and notes. The synchronized catalog contains 151 applications.
- Correct cumulative occlusion-query accounting, including missing distant Red Dead Redemption characters.
- Mario Kart World: corrected shadow mip image views and frame-step pacing. Broader texture/queue lifetime, vector/mesh, write-mask and archive indexing fixes improve rendering and preparation.
- Optional Switch 2 Bluetooth controllers, controller-join prompts, general Unity/Unreal frame-rate controls and build-independent frame-step rules.
- Correct M1 iPad CPU baseline, keyed shader packages, content-meta package scanning, pulling vertex libraries, optional shader-file packing and custom icons.

Existing game apps receive the engine when prepared again. Signature renewal retains their current engine. Original game files, RomFS, installed apps and progress are preserved. Mac evidence does not establish current iPhone/iPad gameplay. See [integration review](../upstream-reviews/2026-11-09.md) and [validation PR](https://github.com/nalancer08/nxnative-easy/pull/32).
