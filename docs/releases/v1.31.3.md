# nxnative Easy 1.31.3

- One clear “Use this Mac’s iCloud” button replaces the duplicated account card and action. Other-account guidance opens only when requested; continuing without iCloud shows a local-save warning.
- The welcome landscape is alive: move the pointer for depth, drag to rotate, or click to dissolve it into a glowing particle sphere and watch it reform. Keyboard Enter/Space works too.
- Reduced Motion shows a stable scene. Animation pauses when inactive, uses bundled resources only, and falls back to the original artwork if WebGL is unavailable.
- Shared-folder selection verifies that the folder belongs to iCloud Drive before changing the current connection.

This update preserves your games, saves, library and signing account. The system iCloud account is managed in macOS; it remains independent of the account used to install apps.
