# nxnative Easy 1.32.0

Engine 1.0.2 brings the complete reviewed original main through `865cc35fad7034d17c2190f8ce349f61f5bcaba1`: 193 upstream commits, preserving Easy's library, installer, touch profiles and save safeguards.

- The catalog grows from 130 to 143 applications, with artwork and both language galleries/website kept together. Super Mario 64 and Sunshine belong to the All-Stars parent app.
- Mario Kart World now has a Mac profile. The checked base-version dump builds a complete Mac app and reaches an interactive race on an M2 Max. Exact builds and remaining limits are in the game note; this does not establish iPhone/iPad support or a full-game playthrough.
- Decrypted NUP inputs gain title/version/update identification and Mac preparation without keys, with integrity and stale-input checks before compiling.
- Renderer, SDK, memory, AV1 decoding and multi-program improvements are included. The new iOS portrait/live game menu keeps Easy's four editable touch profiles.
- The legacy Mac anisette provider receives a consistent login/verification identity, addressing issue #19 without rewriting other providers. The fix is covered by helper/header tests; real-account evidence is limited to the reporter's original test.
- Build activity is written to its private retained log before the UI receives each line, avoiding a race found during release checks.
- Conflict-preserving cloud history, exact install identities, local progress and old game packages remain intact. Stale-cache cleanup stays opt-in.

Updating Easy does not replace the runtime inside an existing game. Prepare a game again to receive engine 1.0.2, then update over its existing installation. Signature-only renewal reuses the registered IPA. Keep the existing game installed and retain its original account/team identity.
