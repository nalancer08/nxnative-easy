# nxnative Easy 1.31.6

- The launcher uses one compact native macOS toolbar alongside the window controls. The extra custom header is removed. Navigation stays together, while engine version, Add game and profile share one aligned trailing group.
- Engine and Add game remain readable labels. Back appears only when there is somewhere to return. Toolbar controls use one selection treatment and compact desktop sizing.
- The game hero is shorter. Its primary action, game version and maintenance reason sit together; the duplicate Review action, destination dropdown and repeated save-count metadata are removed.
- Device destinations use one compact panel. Manual backups/imports are grouped in Manage saves instead of repeated on every device row. Installation, renewal, content-copy and save safeguards are unchanged.
- Supporting buttons have distinct hover and pressed fills, and the contrast check also covers the hover surface.

Engine 1.0.1 is unchanged. This update does not recompile games or replace progress.
