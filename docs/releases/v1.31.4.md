# nxnative Easy 1.31.4

- Engine versions now read 1.0.0, 1.0.1 and so on. Each known game preparation compares its engine with the current 1.0.1; hashes remain in technical details. These versions are independent of the Easy app version.
- A profile avatar stays in the header, with iCloud connection status, last successful check, selected folder and a shortcut to the real account in macOS Settings. The avatar is explicitly this Mac’s local profile; Easy does not claim to know your iCloud email or photo.
- Selecting iCloud waits for a successful scan, then confirms the selected connection before opening the library. Failure stays visible and can be retried. A system-account change requires reconnecting and keeps all save files.
- The header adapts at narrow window sizes while retaining the engine and profile controls.

This update changes the launcher and version metadata. It does not update the engine itself, recompile games, alter signing identities or replace your progress. A newer engine number alone never requires recompiling every game.
