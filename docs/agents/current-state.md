## Product and owner intent

nxnative Easy is a Steam-like personal launcher, with a game list on the left and the selected game's detail on the right. Add an owned game, choose Mac or iPhone/iPad, prepare, install/play. No games or keys are included or downloaded. The compatible-games catalog is an in-window page, distinct from the owned library. Avoid separate administrative Devices/Save tabs: device presence, installation/renewal, save history and manual export belong inside each game.

Saves are central. The owner wants automatic iCloud continuity across Mac/iPhone/iPad, immutable history and both copies retained on conflict. Adding a game without saves also creates a library entry; cloud saves can identify a game whose files are not present yet. iCloud uses the device's system account and is separate from the Apple account used to sign apps. Drive APIs do not expose the owner's Apple email/photo: never invent identity from the local Mac profile. Stock/unmodified Switch consoles cannot import/export arbitrary SD saves; do not promise otherwise.

Preserve originals, RomFS, working signed apps, lightweight unsigned IPAs, code, keys and progress. Never uninstall an existing game to update it. Keep bundle/team identity, backup-first recovery gates, explicit device registration and signing consent. Agent tests never sign/install on owner devices. Copy game content means RomFS, not save backup. Local/manual export works without signing login.

## Technical boundaries to keep clear

Native rewriting does not recover the original Unity/C#/C++ game project. Data mods and build-gated executable patches are possible, but a compiled app is not editable original game source. Nintendo online services and LAN/netplay are unsupported at the integrated pin; a Nintendo Switch Online subscription does not bridge them automatically.

The ARM64 installer uses open isideload/idevice code, not Sideloadly's proprietary source or binaries. Preserve its real capability boundaries and never claim full Sideloadly parity from compilation alone. REA is optional static analysis of the owner's original NSO exported to ELF, not a required player step or a way to obtain proprietary source.

Mac committed saves live under `~/Library/Application Support/nxnative/<TitleID>/save` (with `save_device` where used); iOS games use their app's Documents/save and save_device. RomFS is game content, not saved progress: copying RomFS must never be labelled a save backup. Signing login is unnecessary for read-only save export or content copy. The portable save API was deferred by the owner in favor of local/manual transfer and then iCloud continuity; don't restart cloud-server work without a new request.

Switch 2 encrypted NSP/XCI extraction is not supported by this integration. Already decrypted dumps and NUPs are the Mac flow. An unknown title/build is not made compatible merely by renaming files or borrowing another game's fixed patches.
