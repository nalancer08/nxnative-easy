## Validation

- Full Python sweep: 148 modules, 1,255 tests, 45 skips, zero failed modules.
  Separately activated all 22 synthetic Ampere/control-flow/first-store tests
  against the pinned translator; no skips in that run.
- Python lint/type ratchet: 391 existing findings, zero new findings.
- Complete native host and GPU tests passed on this M2 Max, and the Mac host
  compiled after the shader rebuild. The initial AV1 fixture failure is explained
  below; both explicit branches now pass without modifying decoder behavior.
- Dread shader build: 1,010/1,010 under chain `e047be1b6829` for Mac and iOS,
  359 pulling, 651 alpha and 173 logic libraries, zero variant failures.
  All 2,193 Metal artifacts per target reused matching compiler/content cache
  entries. This is a full retranslation/validation, not a claim that unchanged
  MSL was physically compiled again. Existing game caches remain untouched.
- Production iOS source/Swift/resource build and link passed with synthetic
  modules, unsigned. No account login, signing or device installation was tested.
- Native bilingual catalog previews use synthetic preferences and show all
  130 profiles. Catalog/galleries pass the shared generator check.
- Real ZBIC synthetic bytes roundtrip and wrong-expanded-size rejection passed;
  the exact corresponding source archive passed its pinned SHA-256 check.
- The bilingual Astro build and all 130 public catalog assets/links passed.
- The static impact map covers the new AV1 helper and previously unmapped shared
  files. Read-only harness discovery under the actual game-folder workspace found
  no registered Mac build (`tools/dmhost`) for a gameplay route; no gameplay
  regression result is claimed and no save or global Metal-cache cleanup was run.
- Desktop/portable ZIP, current/legacy updater and exact-head CI results
  are recorded in the PR before main publication. A compile is not gameplay.

The codec test was made hardware-independent: the original test assumed an AV1
decoder even on M1/M2. It now separately verifies the no-sequence-header path and
the existing unsupported-device black-placeholder path, without changing decoding
behavior or claiming an AV1 movie was decoded on this Mac.

The first exact-head C-lint run found two additional findings in the original’s
new geometry-hazard fixture. Its command allocation and readback-buffer
allocations are now checked, and the fixture removes its retained program serial
after GPU completion. The corrected physical GPU test passed all 57 checks.
The baseline was not enlarged. LLVM 23’s path trace stops tracking the program
after `serial_put`: its explicit CF retain is owned by the custom `g_by_serial`
hash map and released by `serial_del` after GPU completion. That proven false
positive has a narrowly scoped, explained `NOLINTNEXTLINE`, following the
repository’s lint policy. The final CI run must verify the fixture before publication.
