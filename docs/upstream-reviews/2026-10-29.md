## Accepted changes

- 91 upstream commits in the integration range; one feature is explicitly reverted below. Sixteen added profiles and ten changed profile definitions: 114 profiles in the app, bilingual galleries and Astro website. Game notes retain upstream testing scope.
- Graphics fixes for buffer texture offsets, storage writes, channel layouts, vertex stream bounds, sampler borders, alpha/logic operations and feedback passes. Shader chain `b3ca4b7c621f` and its locked translator are carried together.
- H.264 end-of-stream/reordering, audio renderer SDK layouts, Nintendo controller label mapping and iOS view-relative motion improvements. Our touch editor and four per-game profiles remain intact.
- Safer parser checks, sparse-base handling, title identification without filename/ticket assumptions, retained Mac shader libraries during iOS builds and Mac minimum-OS/archive targeting fixes.

## Preserved fork behavior

- Keep the polished English/Spanish README and Astro website, shared Apple account, scoped device discovery, explicit installation consent, local save export, portable updater and tools, progress/logs, launch options and preview-based cleanup.
- Combine `nx_extract --title` / sparse checks with our metadata-only `--inspect`; neither path extracts game data during identification.
- iOS accepts case variants of `romfs.img`, while full packages retain bundled-content priority. Do not move/delete existing external RomFS or save folders on startup.
- Pin Capstone to major version 5 in our source bootstrap and release workflow, matching the newly enforced upstream rewriter contract.
- Quote the new GPU border-test executable path so tests work in a workspace containing spaces. Update the synthetic NSO fixture to real page alignment; retain the loader validation. Fix the README toolchain link and its playing-guide anchor.

## Deferred by owner policy

The iCloud synchronization feature from [`123c7ff0ddcc`](https://github.com/seedds/nxnative/commit/123c7ff0ddcc188319da5bd035ac2cb2a86e1213) is deliberately reverted, including cloud UI, automatic save import/export and write hooks. The owner requested local saves and manual sharing before considering a cloud service. Existing saves, identities, installed apps and game outputs are not migrated or replaced. This exception is recorded in `docs/upstream-sync.json` for future reviews.

- Locked tools verified. Separate real Metroid Dread shader rebuild: 1,010/1,010 shaders for Mac and iOS, 359 pulling variants, 651 alpha and 173 logic libraries; no compile failures. The Dread host was rebuilt after its profile tables were generated.

- Bilingual Astro production build, all 114 profiles, local links and public-asset checks passed. Python lint ratchet: 392 baseline findings, zero new.
- Full frontend SwiftUI model/catalog compiled; refreshed English/Spanish catalog previews use synthetic state.

The gameplay regression harness found no registered Mac game build under the local game folders, so it could not run a before/after gameplay route. These checks do not claim physical iPhone gameplay for each new profile. No Apple signing/install, save restoration or user-game cache cleanup was performed. Existing game files and saves remain in place.
