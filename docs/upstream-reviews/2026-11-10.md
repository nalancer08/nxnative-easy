## Imported engine improvements

- Universal native AOT shader translation and package extraction remove the player-facing .NET SDK dependency. Easy's custom metadata-only `--inspect` is rebuilt into the universal native extractor, with source-generated JSON and embedded source-hash verification on both architectures. The app reads original package identity, version and updates without compiling. Managed SDKs are removed only from the staged portable bundle; system SDKs and installed rollbacks are preserved. Native runtime notices remain bundled.
- Faster optimized Mac host, shader uniform bounds, NVN2 mesh/fragment handling, shared-memory grids and half matrix arithmetic. Texture pool retirement, stand-ins, written spans, image sRGB, queue allocation and uniform blocks improve rendering correctness. Missing pipeline bases are negatively cached.
- GPU timestamp reports now measure their actual segment while excluding host-translation gaps. Exact pending-report ranges avoid refusing an entire uniform page; upstream measured the benefit on Ori and the Will of the Wisps. These two commits arrived during validation and are included in this final frozen cut.
- Short-sleep/yield backoff reduces unnecessary CPU wakeups. System-register handling, HID Home protection, rumble exception handling, movie playback and scaler lifetime improve host behavior.
- Bracketed workspace paths no longer hide patches; DLC uses its parent application identity. SDK-derived iOS framework filtering retains valid framework links. Sparse file reclamation and disk reserve behavior are retained.

## Pipeline lifetime correction after the local gate

A second plain cold run also failed in the private cache. The caller drained each returned pipeline before its archive period serialized. The period now owns successful render/compute results through serialization, then releases them after either success or failure. No retry, delay, global lock or feature disable was added. See [the shared finding](../reference/shaders.md#captured-pipelines-released-before-archive-serialization).

The new weak-observer regression fails four lifetime cases on the previous source (81 checks, four failures), and passes all 81 on the correction. Two independent fresh Zelda prebuilds without diagnostic flags complete all 17,742 pairs with no RED lines (202.5 and252.9 seconds; second peak host RSS444.7MB). Their production source matches runtime a4aa8959d591. Final paired game comparisons, affected GPU/iOS/static gates and the portable release checks remain required. Private framework internals are opaque; evidence and the controlled ownership test support this bounded correction rather than a claim about every driver.


The imported short-sleep test froze its polling clock but used real nanosleeps inside `sleep_precise`, repeating each timer up to16 times without clock progress. CI hit its20-second alarm although local host runs passed. The fixture now pairs the frozen clock with a duration-checked synthetic nanosleep; real pthread condition waits and the signal handshake remain exercised. Three focused runs pass (0.313/0.012/0.012s), and the final CI host suite remains a release gate. Production scheduling code is unchanged by this fixture adaptation.
