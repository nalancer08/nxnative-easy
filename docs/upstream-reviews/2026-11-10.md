## Imported engine improvements

- Universal native AOT shader translation and package extraction remove the player-facing .NET SDK dependency. Easy's custom metadata-only `--inspect` is rebuilt into the universal native extractor, with source-generated JSON and embedded source-hash verification on both architectures. The app reads original package identity, version and updates without compiling. Managed SDKs are removed only from the staged portable bundle; system SDKs and installed rollbacks are preserved. Native runtime notices remain bundled.
- Faster optimized Mac host, shader uniform bounds, NVN2 mesh/fragment handling, shared-memory grids and half matrix arithmetic. Texture pool retirement, stand-ins, written spans, image sRGB, queue allocation and uniform blocks improve rendering correctness. Missing pipeline bases are negatively cached.
- Short-sleep/yield backoff reduces unnecessary CPU wakeups. System-register handling, HID Home protection, rumble exception handling, movie playback and scaler lifetime improve host behavior.
- Bracketed workspace paths no longer hide patches; DLC uses its parent application identity. SDK-derived iOS framework filtering retains valid framework links. Sparse file reclamation and disk reserve behavior are retained.

## Fork adaptations and boundaries

The original mutable newer-wins/pruning cloud protocol remains excluded. Easy keeps immutable revisions, both divergent saves, two-folder transactional recovery and account separation. Directory RomFS stays the frontend default, stale-cache pruning remains opt-in, and original game files, keys, installed games and progress are never test outputs. The native metadata reader is checked against source before accepting its response. Its anonymous reflection serialization was replaced with an AOT-compatible generated context before execution.

Test fixtures were adapted for explicit game selection, moved shader helpers, a newly required empty cbuf list and a missing test-only key symbol. The mip test now frees its allocated linear command copy. An unused shader import was removed, and the chain header regenerated. These are not player-save migrations.
