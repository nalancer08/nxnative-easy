## Preserved and adapted fork behavior

Keep the bilingual frontend, four per-game touch-control profiles, native
installer, saved Apple session/explicit consent, scoped device queries, manual
save export, optional full/light IPA output, complete Mac apps, retained app
identities and portable updater. Game folders, keys, existing working packages
and saves are not migrated or deleted by this update.

- Metadata-only encrypted-package inspection still drives builds from CNMT/NACP
  rather than filename guesses. Its verified metadata adapter accepts the new
  upstream scanner arguments and refuses a conflicting requested title.
- Existing Switch package preparations retain directory RomFS extraction and
  the folder-based iOS transfer protocol. The new dump flow is Mac-only and uses
  the upstream image path inside the complete Mac app. This is not an implicit
  migration of existing iOS content to an image-only transfer protocol.
- Both bundled RomFS and bundled DLC take priority in an explicitly full update;
  external content is retained. Account-free export/copy remain separate.
- Older shader caches stay by default, including on the CLI. Upstream's new
  pruning logic is retained as explicit `--prune-stale-caches`; Easy continues
  using its separate preview/locks. No cache deletion was run on user games.
- Gallery parsing accepts upstream's new `<small>` captions as well as `<sub>`.
  The Switch 2 platform limitation survives generation and Spanish rendering;
  the JSON catalog remains stable on a subsequent check without upstream HTML.
- The fake Metal compiler fixture uses a portable interpreter entry point:
  an executable shebang naming a Python under a path with spaces cannot run.
  Real Metal compilation is verified separately; the fixture is not a bypass.

## Cloud exception remains necessary

The owner approved optional iCloud continuity, but the earlier
[reproduced safety findings](2026-10-29-ecosystem.md) remain in this upstream pin.
The native synthetic probe again reproduced a half-applied two-folder restore
and an older diverged local snapshot replacing the shared latest snapshot.
The displaced remote has a backup; this is not a claim that every copy is lost.

Cloud UI and runtime write hooks remain excluded. The new metadata-stream close
fix and folder-picker fix do not solve the two hazards. This exception is
recorded separately from integrated history, so a future merge cannot silently
turn synchronization on. Local saves and manual export remain available.

- Full Python sweep: 143 modules, 1,148 tests, 28 skips. Three initial failed
  modules were corrected and rerun completely (README Xcode version, agent-guide
  word limit, and the mock compiler shebang). Modified fork paths and new dump,
  source-identity, scanner-adapter, cache-retention, gallery and native content
  tests were run again separately after their changes.
- Complete native host and graphics/GPU test commands passed on this Mac,
  including real Metal checks. Mac host compiled again after the shader rebuild.
- Real Metroid Dread shader inputs, isolated new output: 1,010/1,010 shaders for
  Mac and iOS, 359 pulling, 651 alpha and 173 logic libraries; zero variant
  compilation failures. Translation chain `b7cd656abd7c`; locked translator,
  SPIRV-Cross and both actual Metal compilers verified against the lock.
- Production iOS source build/link with synthetic modules and content, unsigned,
  passed. No Apple login, signing identity use or device installation occurred.
- Desktop app/worker compiled, with refreshed bilingual catalog previews rendered
  from the real view and synthetic preferences. No real Apple account was loaded.
- Catalog check and bilingual Astro production build/local-link/public-asset
  checks passed with all 124 profiles. Python lint/type ratchet has no new finding.
- The gameplay harness found no registered Mac game build in the local folders;
  its quick-run command could not execute a gameplay route. No local Bananza or
  Mario Kart World files were provided for actual gameplay. Upstream's game
  notes retain the source/platform of their evidence.

PR checks must pass before main integration. Publishing an app or a successful
compile does not establish gameplay for an untested game/platform. Existing
prepared apps need deliberate preparation again to gain this runtime.
