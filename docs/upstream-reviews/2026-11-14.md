## Integration

- Parallel per-game host compilation and object reuse. Extraction keys include the source-matched reader, input packages, and the image/directory layout. Easy still builds directory RomFS for its mobile transfer path.
- Mac game packs separate and reuse signed data bundles. The shared app identity and Easy's export transaction remain in place.
- Updated GPU synchronization, texture lifetimes, shader translation and pipeline archive prewarm. Retained Easy's pipeline ownership through Metal serialization. Adapted [#2691](https://github.com/seedds/nxnative/pull/2691) to restrict runtime archive cache cleanup to old directories.
- Keep Easy's immutable save history and recovery gates on both macOS and iOS. Automated runs remove Easy's cloud folder from their environment. The upstream single-file cloud protocol remains excluded.
- [Mario Kart World 1.8.0 frame-step changes](https://github.com/seedds/nxnative/commit/6815810d) are in main. The separate complete [1.8.0 support proposal](https://github.com/seedds/nxnative/pull/1252), [iOS work in progress](https://github.com/seedds/nxnative/pull/1383) and [low-memory defaults](https://github.com/seedds/nxnative/pull/2606) were reviewed and left out pending a matching local version/device test.
